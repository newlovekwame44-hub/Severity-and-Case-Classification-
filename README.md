## Severity & Case Classification

For each case I checked two things. Seriousness: did the reaction cause death, threaten life, need hospitalization, leave lasting disability, or count as medically important? Expectedness: is the reaction already described in the drug's label or known profile?

| Drug | Reaction | Seriousness | Expectedness |
|---|---|---|---|
| Amoxicillin | Skin rash, itching | Non-serious | Expected |
| Ibuprofen | GI bleeding requiring hospitalization | Serious | Expected |
| Metformin | Lactic acidosis | Serious | Unexpected |
| Atorvastatin | Mild elevated liver enzymes | Non-serious | Expected |
| Levofloxacin | Tendon rupture | Serious | Unexpected |

### Reasoning

**Amoxicillin.** A rash and itching are common, mild allergic reactions that clear up after stopping the drug. They are in the label and don't meet any seriousness criterion.

**Ibuprofen.** Bleeding that lands a patient in hospital is serious. It is still expected, because GI bleeding is a well-known NSAID effect.

**Metformin.** Lactic acidosis can be life-threatening, so it is serious. I classed it as unexpected because the scenario's reference information doesn't list it.

**Atorvastatin.** A mild rise in liver enzymes is a known statin effect. It needed only monitoring, so it is non-serious and expected.

**Levofloxacin.** Tendon rupture can cause lasting disability, so it is serious. I classed it as unexpected for the same reason as metformin.

### Summary

Three cases are serious, two are non-serious, and two are unexpected.

### A note on my assumption

I judged expectedness against the scenario's reference information. In real labeling, lactic acidosis with metformin and tendon rupture with levofloxacin both carry boxed warnings, so they would count as expected there.
